# Voice Input Sync

手机语音 / 文字实时同步到电脑输入框的本地工具。

## 当前状态

这个项目目前已暂停维护，保留为公开作品集和阶段性工具记录。

它曾经是一个非常实际的小工具：用手机输入语音或文字，然后把内容同步到电脑当前输入框。后来随着微信输入法等工具在电脑端语音输入体验变得足够方便，这个项目的日常价值降低了。

## 它想解决什么问题

当时的核心问题是：电脑上长文本输入不够顺手，尤其是想用手机语音快速输入，但最终内容又需要落到电脑里的某个文本框、文档或网页输入区域。

这个项目想做的是：

- 手机作为输入端
- 电脑作为接收端
- 局域网优先连接
- 必要时使用互联网备用地址
- 把手机上的语音转文字或手动输入同步到电脑当前输入位置

它解决的是“手机输入舒服，电脑承载工作流”之间的断点。

## 设计思路

设计上尽量贴近真实使用场景：

- 手机扫码打开输入页
- 电脑端启动本地服务
- 手机和电脑在局域网中直连
- 电脑侧尽量模拟真实键盘输入，把内容送到当前焦点位置
- 提供便携版、启动脚本、托盘和设置窗口，降低使用门槛

这个项目的重点不是炫技，而是让“手机输入 -> 电脑落字”这个动作足够顺滑。

## 后来的反思

这个项目后来不再继续维护，主要是因为已有输入法工具已经覆盖了核心场景。

尤其是微信输入法这类工具，把电脑端语音输入做得足够方便之后，原来需要自己搭桥的部分就不再那么必要了。

这也是一个很典型的 AI / 工具时代变化：很多自建小工具在当时确实解决痛点，但当平台级工具补齐能力后，自建工具就应该自然退场。

## 是否继续维护

暂不维护。

这个仓库会保留为一个本地协同输入工具的原型记录。如果后续重新启动，可能会转向更细分的场景，比如局域网离线输入、临时接力、特殊输入环境，而不是和成熟输入法正面重叠。

## 技术栈

项目主要由 PowerShell、Python 和本地 HTML 页面组成，包含便携版启动、二维码连接、局域网服务、托盘控制和基础更新检测等能力。

## 作品集说明

这个仓库展示的是一个非常具体的工作流自动化尝试：不是为了做一个大产品，而是把一个高频输入动作打通。它现在不再是主力工具，但仍然记录了一个真实需求从痛点到原型的完整过程。
